# Competitive landscape: AI deep-research tools (as of 2026-10-09)

Purpose: position Quorum (local macOS app; blind parallel agents → validator critics → one short answer with per-claim confidence, explicit conflicts and click-through verified quotes; runs on the user's Claude subscription) against the tools people use today.

**How to read this.** Every claim carries a link. Tags: **[V]** = vendor's own claim, **[I]** = independent (third-party review, study or report), **[V→I]** = vendor claim relayed by a third party, **unverified** = could not be confirmed from a fetchable source. Raw per-area notes with more detail and more links are in [`research/`](research/) (01–05); the benchmark draft is [`research/06-benchmark-protocol-draft.md`](research/06-benchmark-protocol-draft.md).

**Method and limits.** Five research subagents did the first-pass reading; I re-fetched the load-bearing claims myself (DeepTRACE's table, Perplexity's 2026 changelog entries, Manus's Wide Research docs) and they held up. Everything else is as good as the cited source. openai.com and perplexity.ai blocked the fetcher, so OpenAI and Perplexity facts lean on press coverage and a changelog mirror. Image content could not be viewed, so "screenshots" below are links to pages that contain them. "Not documented" means not found in the docs I could read, which is weaker than "doesn't exist".

## Top findings

1. **Parallel fan-out is confirmed commodity.** Manus, Kimi, Perplexity Computer, Claude Research, GPT-Researcher and a pile of Claude Code skills all do it ([Manus](https://manus.im/features/wide-research), [Kimi](https://www.kimi.com/en/help/agent/agent-swarm), [Anthropic](https://www.anthropic.com/engineering/multi-agent-research-system)).
2. **"Trust" is no longer an empty field, but nobody has the full stack.** Perplexity shipped **Check Sources** (Jul 27, 2026: "verifies claims against the underlying evidence") and a Source Context Panel [V, changelog mirror](https://releasebot.io/updates/perplexity-ai). Consensus shipped quote-on-hover **Citation Grounding** ([V](https://consensus.app/home/workshops/citation-grounding/)). Parallel's API returns per-field excerpts plus a calibrated confidence label ([V](https://www.parallel.ai/blog/introducing-basis-with-calibrated-confidences)). What I found **nowhere**: a consumer app combining blind multi-agent research + deterministic quote verification + per-claim confidence + side-by-side conflicts on *general web/business* research.
3. **The independent evidence says the problem is real and measurable.** DeepTRACE (ICLR 2026) found unsupported-statement rates from 12.5% (GPT-5 Deep Research) to 97.5% (Perplexity Deep Research), citation accuracy 50–79%, and 55–95% one-sided answers on debate questions ([I](https://arxiv.org/html/2509.04499v1), 2025-era systems, LLM judge). Manus documents **no** citation or verification mechanism at all ([V](https://manus.im/docs/features/wide-research)).
4. **The visual bar just rose.** Claude, ChatGPT (GPT-6 "Intelligent UI", Oct 7–8) and Perplexity (Oct 5) all now render inline interactive charts. "Beautiful with charts" is table stakes within weeks; "beautiful *and every number is a verified claim*" is not.
5. **The biggest threat is the platform Quorum runs on.** Anthropic already ships a CitationAgent, Citations API quote spans, inline visuals, and reviewer agents that check citations (Claude Science, science-only, beta).

## 2. How competitors present results visually

I could not view image content, so each example links to a page that contains screenshots or a description; **screenshot hands-on is the first follow-up** (see §6).

**Table stakes as of Oct 2026** (every major tool has most of these): inline numbered/domain citation chips; hover preview of the source; sources sidebar; full-screen report viewer with table of contents; live progress with a visible, editable plan; PDF/Word/Markdown export; tables; inline interactive charts.

- **ChatGPT — the document viewer.** Feb 2026: full-screen viewer, table of contents on the left, expandable citations list on the right, export to PDF/Word/Markdown ([I](https://www.androidheadlines.com/2026/02/chatgpt-deep-research-full-screen-document-viewer-update.html), thread with screenshots: [MacRumors forum](https://forums.macrumors.com/threads/chatgpts-deep-research-mode-gets-a-fullscreen-document-viewer.2477526/)). Reports still criticised as "a wall of text with very long paragraphs" ([I](https://www.gradually.ai/en/deep-research/)). Oct 7–8, 2026: GPT-6 "Intelligent UI" builds chat answers from a fixed component library (≈70 components per one teardown; interactive charts, editable graphs, maps) with a user control to dial visuals down ([I](https://techbriefly.com/2026/10/08/openai-chatgpt-gpt-6-interactive-visuals/), [I, teardown not confirmed by OpenAI](https://www.explainx.ai/blog/chatgpt-intelligent-ui-gpt-6-interactive-answers-explained-2026)). A fixed component library is the architecture worth noticing: consistent, safe, streamable.
- **Gemini — the most ambitious visuals, gated.** Visual reports add charts, diagrams and interactive simulators with adjustable variables, refinable in Canvas and exportable to Docs; Ultra-only ([V](https://blog.google/products/gemini/visual-reports/), [9to5Google](https://9to5google.com/2025/12/16/gemini-deep-research-images/)). In the API, charts/infographics are drawn inline via HTML or Nano Banana only when the prompt asks ([V](https://ai.google.dev/gemini-api/docs/interactions/deep-research)). They disappear if private sources are included ([I](https://www.gend.co/blog/gemini-deep-research-visual-reports-2026)). Google's generative-UI research: raters "strongly preferred" per-prompt interactive responses ([V](https://research.google/blog/generative-ui-a-rich-custom-visual-interactive-user-experience-for-any-prompt/)).
- **Perplexity — the citation affordance.** A teardown of its citation UI: domain chips with "+N", hover carousel (1/N), favicon source row, sidebar, Links tab — with the critique that three overlapping routes to sources confuse and there's no per-citation "wrong source" feedback ([I](https://aiuxplayground.com/teardowns/perplexity/citations)). 2026 added Source Context Panel and Check Sources (Jul 27) and inline interactive charts (Oct 5) ([V](https://releasebot.io/updates/perplexity-ai)). Labs/Computer produce dashboards and mini-apps; one reviewer found 10-K charts "impressive" but the app broken ([I](https://www.nocode.mba/articles/perplexity-labs-review)).
- **Manus — many formats, evidence invisible.** Slides (editable chart data overlay, [images](https://files.manuscdn.com/assets/dashboard/materials/2026/07/14/ccd61331244c5a1b1025225a82bc17180e466143f25cfa6ee97a14ef1067c016.webp), [images](https://files.manuscdn.com/assets/dashboard/materials/2026/07/13/2b5da8b81e13a237e79a389c82bb68bcc6ad820378c7da24cb4aa74a2cf2a1e8.webp) from [its blog](https://manus.im/blog/manus-ppt-slides)), dashboards, PDF, web pages ([V](https://manus.im/docs/features/data-visualization)). Wide Research output is a "sortable matrix" ([I](https://venturebeat.com/business/youve-heard-of-ai-deep-research-tools-now-manus-is-launching-wide-research-that-spins-up-100-agents-to-scour-the-web-for-you)); reviewers saw both clean spreadsheets and "a malformed CSV with merged cells" ([I](https://www.taskade.com/blog/manus-ai-review)); no citations shown in decks ([I, competitor](https://plusai.com/blog/manus-ai-slide-generator-review/)).
- **Claude — inline charts that raise perceived confidence.** HTML/SVG interactive visuals, "beautiful, tabbed, interactive charts unprompted" but "Interactive slop is still slop" ([I](https://news.ycombinator.com/item?id=47352751)); vendor page [V](https://claude.com/resources/articles/claude-builds-visuals).
- **Elicit — quote cards.** Click a table cell or report claim to see supporting quotes and reasoning, "1 of 6" counter, most relevant first ([V](https://support.elicit.com/en/articles/4168449), [I](https://support.elicit.com/en/articles/3090497)). No confidence indicator documented.
- **Consensus — the Meter.** Aggregate Yes/No/Possibly bar with the classified papers listed beneath, verbatim quotes ([V](https://consensus.app/home/blog/consensus-meter/)); critics call it an equal-weight vote ([I](https://aarontay.substack.com/p/a-2025-deep-dive-of-consensus-promises)).
- **Scite — conflict as a list.** Citing sentences labelled supporting (green) / mentioning / contrasting (blue) with tallies and filters ([V](https://help.scite.ai/zh/article/how-does-scite-work-1eje9i9)); per-class accuracy ~97% / 64% / 59% ([I](https://library.hkust.edu.hk/sc/trial-scite/)). Best prior art for showing *disagreeing evidence*.
- **NotebookLM — the source pane reference.** Numbered citations open the source at the passage (highlight itself unconfirmed) ([I](https://learnprompting.org/blog/notebooklm-guide)); Studio outputs: mind maps, infographics, slides, audio ([I](https://9to5google.com/2026/02/06/notebooklm-slide-customization/)).

**Evidence about UI design.** Two CHIIR studies (394 and 372 participants): people rarely click citations in any condition; hover cards help quick checks; an **aligned sidebar** held up best as citation density rose ([I](https://arxiv.org/abs/2512.12207), [I](https://arxiv.org/abs/2601.14611)). I found **no shipped product displaying calibrated per-claim confidence** ([I](https://iamvera.ai/blog/ai-confidence-scores-false-certainty/) on why raw model confidence is a weak signal).

**Worth stealing:** aligned evidence pane beside the prose; quote-first chips with "1 of N"; Scite-style labelled conflict list; show the inputs behind any roll-up (Consensus lists them, but weight them); Perplexity-style per-claim check with the check *already run*; Claude Science-style provenance trail; ChatGPT's fixed chart-component library; Manus's editable chart data; a "dial down visuals" control.
**Avoid:** decorative visuals outrunning correctness (HN critique); overlapping routes to the same source (Perplexity); equal-weight meters; visuals that vanish in some modes (Gemini).

| Quote on hover / jump to passage in source | **Taken in academic niches** | Consensus Citation Grounding; Elicit (SR pipeline); NotebookLM |
| Blind parallel agents + adversarial validator critics over *general web/business research* | **Open** — Claude Science (science) and community skills are the nearest; none documented as a consumer app | see §1 |
| **Deterministic** "quote exists verbatim in the fetched page" check | **Open (not documented anywhere I read)** — Citations API guarantees pointer validity, not support or presence of quote in a *web* page the user can re-open; Elicit's own independent eval found quotes matched only 46% | [I](https://www.cambridge.org/core/journals/research-synthesis-methods/article/using-elicit-ai-research-assistant-for-data-extraction-in-systematic-reviews-a-feasibility-study-across-environmental-and-life-sciences/C97DAEC70C3173A260F0B12E729E7250) |
| Per-claim confidence **derived from blind agreement + critic outcome**, shown in a consumer UI | **Open** — nobody shown; Parallel is API-only | — |
| Conflicts shown as side-by-side claims with both quotes | **Open for business questions** — Scite does it for papers; Model Council does it between *models* | DeepTRACE: 55–95% one-sided on debate queries ([I](https://arxiv.org/html/2509.04499v1)) |
| One **short** trusted answer instead of a long report | **Mostly open** — most tools ship long reports; verification burden is a documented complaint; DeepFact: unassisted PhD experts verified claims in DR reports at only 60.8% accuracy ([I](https://arxiv.org/abs/2603.05912)) | |
| Local app, user-owned files, $0 marginal cost | **Partly open** — every major research product is cloud; Manus's Meta/data-deletion saga gave data ownership fresh salience. *Caveat:* Quorum still sends prompts and page text to the model provider, and the subscription's shared usage pool is also drawn down ("Research can use them up faster", [V](https://support.claude.com/en/articles/11088861-using-research-on-claude)) | |
| "Verified" as a *brand claim* | **Contested and cheap to say** | Perplexity, Elicit and Consensus already use verification language. It only counts if Quorum can publish a number |

**Net:** the open space is narrow but real: *verification of web/business claims that a human can audit in one click, with confidence and conflicts as first-class UI*. It is not "we have agents" and not "we have charts".

**Wide tier note.** Manus, Kimi and Perplexity Computer own the "250 agents → table" story, and Manus documents no citations. If a Wide tier is added, compete on **per-cell verified quotes** (an Elicit-style extraction matrix for the open web), not agent count.

## 4. The three strongest threats

### Threat 1 — Perplexity ships "verified claims" first, with distribution
Check Sources + Source Context Panel (Jul 27, 2026), a finance traceability layer, inline interactive charts (Oct 5), and Deep Research now inside Computer ([V, changelog mirror](https://releasebot.io/updates/perplexity-ai)). That is the same pitch, in a product with a huge user base and a reputation for citations.
- *Reality check:* mechanism and accuracy are **unverified**, and Perplexity's last independent audit was ugly (97.5% unsupported statements, pre-feature; [I](https://arxiv.org/html/2509.04499v1)). "Summarises how well supported" is not a deterministic quote check.
- **Do:** (a) hands-on test Check Sources on the benchmark questions this week and record what it actually does; (b) make Quorum's verification *measurable and published* — support rate, quote-presence rate, calibration curve — so "verified" is a number, not a word; (c) add Perplexity to the benchmark (done in the protocol draft); (d) keep the differentiator in what Perplexity's design makes hard: blind independent agents, critics that can overturn the draft, conflicts as first-class objects.

### Threat 2 — Anthropic (the platform Quorum rides) builds the same thing
Claude Research already has a CitationAgent and parallel subagents; Citations API gives quote spans; inline visuals shipped Mar 2026; Claude Science has reviewer agents that flag incorrect citations and untraceable numbers ([V](https://www.anthropic.com/news/claude-science-ai-workbench)); Managed Agents "outcomes" adds a second-agent gate ([V→I](https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/)). If Research gains a verified-quote pane, Quorum risks being "Claude Research plus a viewer", and it pays rent on Anthropic's usage pool.
- **Do:** (a) benchmark against plain Claude Research as the control arm (protocol arm F) — if Quorum can't beat it on audited support rate and time-to-verify, say so early; (b) own what a general chat product won't: persistent local library, user-owned files, cross-run conflict tracking, the evidence pane; (c) keep the model-provider abstraction alive (other profiles are flagged off, not deleted) as insurance; (d) separately check current Anthropic terms for third-party apps on subscription auth — **not researched here**.

### Threat 3 — Visual quality commoditises faster than Quorum can ship; and the pipeline is cheap to clone
ChatGPT (component-library UI), Gemini (visual reports), Perplexity and Claude all render inline interactive charts within the last ~7 months, free of any extra install; community Claude Code skills already implement "verbatim quote + fact-checker" ([V](https://github.com/comu365/claude-deep-research)). Beautiful charts will not differentiate; HN already says polish inflates perceived confidence without improving correctness ([I](https://news.ycombinator.com/item?id=47352751)).
- **Do:** (a) make every visual *evidence-bound*: each number in a chart is a claim with confidence and a quote, one click away — "no unverifiable pixels"; (b) restraint over chart count, with a dial-down control and a default of text-first, short answer; (c) adopt the proven patterns (aligned evidence sidebar, quote cards "1 of N", Scite-style conflict list) rather than inventing; (d) accept the pipeline is clonable and compete on UX polish, measured verification and the local/owned story.

*Honourable mention:* Manus/Kimi-style Wide tiers if Quorum adds one (see §3) — Manus's credit opacity and absent citations are the opening.

## 5. Proposed benchmark protocol (summary; full draft in [`research/06-benchmark-protocol-draft.md`](research/06-benchmark-protocol-draft.md))

**Arms:** Quorum Quick + Deep; ChatGPT Deep Research; Gemini Deep Research; Manus (Wide Research for list questions); recommended extras: Perplexity with Check Sources, and plain Claude Research as an architecture control.
**Questions:** ~10 real food-tech business questions across six types — conflicting market sizing, competitor/pricing comparison, regulation, contested evidence, one 30–40-row Wide list, and traps (false premise; fresh fact). The owner writes the answer key (coverage checklist, 3–5 anchor facts with primary sources, known traps) **before** any run.
**Equal-ish budget:** default/highest standard mode per product, identical prompt text, no follow-ups, two runs per question; log time, credits/usage and API-equivalent cost; report quality per dollar and per minute. Optional API-matched arm at a fixed ~$5/task.
**Judges:** non-Claude panel (OpenAI-family + Gemini-family + an open-weights judge); each judge doesn't score its own vendor's system; winner only if both position orders agree; owner re-grades a random 30% and discards LLM-judge results if agreement is poor. This fixes the Claude-judges-Claude caveat on the first external run of the existing harness (`Sources/Quorum/Benchmark.swift` already does binary rubric + both-position judging + a Codex cross-family judge, but still includes Claude).
**Rubric (content, blind-normalised Markdown):** claim support 30%, correctness vs key 20%, coverage 15%, conflict & uncertainty handling 15%, decision usefulness/concision 10%, verifiability 10%.
**Mechanical metrics, same tooling for all arms:** URL health; verbatim-quote presence (where quotes exist); support rate (non-Claude verifier given claim + fetched page text, 20% human audit) reported as DeepTRACE-style unsupported-statement rate; calibration by confidence bucket (arms that emit confidence); median seconds for a human to verify 5 random claims; conflict recall on seeded conflicts.
**Presentation track (separate, not blind):** three raters score scannability, evidence-bound visuals, clicks to evidence, legibility of trust signals, from screenshots.
**Pre-registered decision rule:** Quorum claims a trust advantage only if its audited unsupported-statement rate beats every competitor's; otherwise publish the null.
**Caveats to print with results:** n≈10, food-tech only, versions change weekly, verifier errors, owner-written key, lossy format normalisation.
