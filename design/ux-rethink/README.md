# UX rethink mockups

HTML mockups (1440×900, dark) for the Quorum UX/IA rethink. Start at [index.html](index.html) for the
shape comparison and journey. Append `?clean` to any mockup URL to hide the annotation notes.

The written research lives in [`docs/ux-rethink/`](../../docs/ux-rethink/):
[AUDIT.md](../../docs/ux-rethink/AUDIT.md) covers the current app with screenshots, and
[PROPOSAL.md](../../docs/ux-rethink/PROPOSAL.md) covers the IA, concepts, flows, keyboard map, and
data model and engine hand-off.
